# ssfpy
SSFP processing pipelines

# Conda installation
```bash
git clone https://github.com/benoitberanger/ssfpy.git
conda create --name ssfpy
conda activate ssfpy
conda install python=3.12
conda install ssfpy
```

## Extra for IDE debugging
`conda install ipython ipykernel`  
This allows VSCode to run in debugg mode and in a jupyter kernel (to execute cell by cell)
